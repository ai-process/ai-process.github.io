Documentation

Everything you need to run the ai-process stack: the Keystone (KTMS) gateway, the light-tokenmeter usage meter and the ktms-admin console. Each service also ships a full reference in its repository README.

Architecture & deployment

How the three services fit together, with a Docker Compose file for the whole stack.

Keystone (KTMS) gateway

gRPC and OpenAI-compatible APIs, effort routing, fallbacks, limits, batches, speech and images.

Local GPU node pool

Self-registering inference nodes, health states, Smooth WRR balancing and cloud fallback.

Quick start: local node

Connect Ollama, vLLM, TGI or llama.cpp on your own GPU to KTMS in a few commands.

light-tokenmeter

Idempotent usage events behind bearer tokens, daily summaries, lossless ClickHouse copying, Prometheus metrics and greedy vs worthy analysis.

ktms-admin console

Password, OpenID Connect, GitHub or access-proxy sign-in, models, rules and keys, a prompt playground and a spend dashboard.

Prompts for AI assistants

Ready prompts for Claude Code, Cursor or Copilot: integrate a service, configure routing, deploy the stack, add a GPU node, migrate, report spend, review production.
